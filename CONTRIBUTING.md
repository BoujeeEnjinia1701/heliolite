# Contributing

Issues and pull requests are welcome.

- Geometry changes go in `cad/src/` as build123d code. Re-export STEP and STL in the same pull request.
- Keep `bom/bom.csv` in sync with any part you add or remove.
- Record significant design choices in `docs/decisions/` using the template there.
- By contributing, you agree that hardware contributions are licensed under CERN-OHL-S v2 and software contributions under MIT.
